Connection & migration guide

Create a Gemini API key in Google AI Studio, add it here, run Test, then enable it.

Connection tests check model-list access. They do not generate content or confirm billing capacity. Keys belonging to one Google project share that project's rate limits.

For a server or database move, download a protected backup first. Restore it here on the new server with your backup password, then test and enable the connections. Ordinary deployments preserve the server's private vault automatically.

Active, tested connections power the merchant AI assistant. Failed responses offer a support-ticket handoff.
