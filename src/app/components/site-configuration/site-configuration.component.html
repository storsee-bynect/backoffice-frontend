One-time platform DNS setup

In the DNS provider managing your CNAME target, point {{ siteConfig.cnameDomain || 'your CNAME target' }} to your dedicated VPS IP using an A record (IPv4) or AAAA (IPv6). Keep DNS-only mode and remove conflicting address records for this hostname.

Saving this page configures the platform guide; it does not create records at your DNS provider. The target must resolve publicly before merchant CNAME connections work.

Records shown to merchants

  • Root domain: A / Name @ / Value {{ siteConfig.customDomainVpsIps?.split(',')?.[0] || 'your VPS IP' }} (AAAA for IPv6).
  • www or another subdomain: CNAME / its hostname label / Value {{ siteConfig.cnameDomain || 'your CNAME target' }}.
  • Default TTL; Cloudflare DNS-only. Root and www are separate connections. Preserve email MX/TXT records and unrelated subdomains.

The VPS must serve the published storefront and allow ports 80/443. Its domain worker handles routing, HTTPS issuance and certificate renewal automatically. No merchant SSL upload is needed.
